# upstream v0.7.16 Merge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge `upstream/v0.7.16` into the current branch without regressing upstream behavior, then port the safe local-only assistant status, default workspace, and send-shortcut behavior.

**Architecture:** Resolve overlapping UI/runtime files to the upstream implementation first. Remove local implementations superseded by upstream, then add narrowly scoped helpers and integrations with tests. Risky directory-browser, external-editor, and embedded-settings implementations are excluded from this merge and recorded as deferred follow-ups.

**Tech Stack:** Next.js 16, React 19, TypeScript, Node test runner, ESLint, npm and Bun lockfiles.

## Global Constraints

- Preserve all pre-existing untracked files.
- Do not run `next build`.
- Keep upstream package version `0.7.16`, pi packages `^0.80.10`, and Next `16.2.9`.
- Never add the whole home directory to the shared file API allow-list.
- Preserve upstream IME, slash command, file mention, queue, draft, extension UI, mobile, worktree, file upload, and lazy-history behavior.
- Use `useSyncExternalStore` plus module listeners for localStorage-backed shared configuration.
